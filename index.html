All About Web Servers

Abstract

Web servers are the backbone of the World Wide Web. They combine hardware and software to receive HTTP requests from browsers and send back the pages, images, and data people ask for. This site explains how web servers work, how they stay fast and secure, and how they grew from a single machine at CERN into global cloud systems.

Key Terms

  • HTTP: the rules browsers and servers use to talk.
  • Proxy: a machine that forwards requests between users and servers.
  • Load balancing: spreading requests across many servers.
  • Caching: temporarily storing content to serve it faster.
  • Cloud computing: hosting files in remote data centers.
