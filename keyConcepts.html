Key Concepts

Web server

Hardware and software that stores website files and answers requests.

HTTP

HTTP (Hypertext Transfer Protocol) is the rules used for communication between web browsers and web servers.

Proxy

They are multiple computers and machines that transfers the HTTP requests.

Caching

Caching is storing temporary data, so that it can be accessed more quickly.

Ports

Ports are a way for computers and web servers to figure out where to send and find other machines.

Cloud Computing

When multiple servers are used to store and deliver content, usually in remote data centers.
