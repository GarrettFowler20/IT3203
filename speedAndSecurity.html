Speed and Security

Static vs Dynamic

Static: Static webservers stay the same over time and don't constantly change. Static web servers are usually faster than dynamic servers, but have a limited pool of information to be requested.

Dynamic: Dynamic web servers, generate new files when the user request them. While these are more complex and harder to maintain, they give personalization to the user and allows them to interact with more and get addition information.

How to make it faster

  • Load balancing: Load balancing distributes multiple incoming requests to many different servers. Instead of just one main server trying to handle everything, multiple are used to balance the requests. It helps improve the overall performance and reliability of the servers.

  • Caching: Caching allows for a web server to temporarily store web content, so it can be requested faster in the future. When there are very large servers, that have a large amount of requests, caching can help process those requests quicker and keep the servers from being overwhelmed.

  • Cloud computing: Cloud computing allows companies to store their websites and files inside of remote data centers. These data centers help host and manage these files, instead of doing it locally on their own servers.

How to make it secure

Possible Threats

  • Malware: Malicious software that be used against web servers to steal information, gain access to websites, or modify files.

  • DDoS Attacks: When an attacker sends a very large amount of requests to a server, which could overload and shut down a server

  • Unauthenticated Access: When someone gets access to a website, a server, or a webpage, without permission. This could lead to important and sensitive data being accessed.

Security Measures

  • Firewalls: A security system that filters out incoming and outgoing HTTP and HTTPS requests bases off of rules.

  • Encryption: A process that converts information or data into a code, to try and prevent malicious access.

  • Authentication: A way to verify a user's identity before granting access to a restricted website or system.
